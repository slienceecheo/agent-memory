# Spec Delta

## MODIFIED Requirements

### Requirement: 向量与全文索引的存储

系统 SHALL 提供全文索引与向量列的存储能力，供检索使用。
全文索引 MUST 包含产生该记忆的原始文本，且 MUST 支持按相关性排序。

#### Scenario: 写入时同步索引
- **WHEN** 写入一条带文本与向量的条目
- **THEN** 全文索引与向量列同时可用，且可通过词面查询命中该条目

#### Scenario: 原文可被检索
- **WHEN** 一条记忆由某句原文产生
- **THEN** 该原文被索引进全文索引，可用其中出现的词命中

#### Scenario: 按相关性排序
- **WHEN** 执行词面检索
- **THEN** 结果按 BM25 相关性降序返回，而不是按版本号或写入序

#### Scenario: 中文词面查询可命中
- **WHEN** 用两个汉字组成的词查询中文正文
- **THEN** 能命中包含该词的条目

#### Scenario: 索引与主表一致
- **WHEN** 条目被取代或撤回
- **THEN** 它不再出现在"当前有效"的全文检索结果中，但仍保留在时间线里

#### Scenario: 向量维度不符
- **WHEN** 写入的向量长度与存储声明的维度不一致
- **THEN** 系统报错并拒绝写入，而不是静默截断或补零

#### Scenario: 单字查询的已知限制
- **WHEN** 用单个汉字查询
- **THEN** 行为按文档所述的降级策略执行，且该限制被明确记录

## ADDED Requirements

### Requirement: 原始文本的保存

系统 SHALL 保存产生每条记忆的原始文本，使检索层能够用原文中的词找到它。

#### Scenario: 原文随记忆保存
- **WHEN** 写入一条记忆并附带原始文本
- **THEN** 该文本被持久化，且可通过条目 id 读回

#### Scenario: 未提供原文时兼容
- **WHEN** 写入时未提供原始文本（历史数据或纯结构化写入）
- **THEN** 写入成功，该条目的原文为空，且不参与词面召回

#### Scenario: 原文不覆盖既有值
- **WHEN** 同一条记忆被更新
- **THEN** 原始文本只在显式提供时更新，不被自动清空
