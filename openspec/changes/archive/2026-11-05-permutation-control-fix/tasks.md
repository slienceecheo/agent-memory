## 0. 为什么要有这个变更

**第二十次归档（`lexical-provenance`）的核心结论是错的。**

它写 `sample p=0.0079 显著`，并据此得出"结论分裂"。
**那个 p 是被污染的**：置换检验的对照组把 C 组（未召回）混了进去。

```python
# A 组与 B 组做检验（C 组与重叠无关，单独报）      <- 注释
_, p = _perm_test(a_vals, b_vals + list(groups["C"].values()))   # <- C 混进来
```

- [x] 1.2 三个口径的对比

  | 对照 | sample p | billing p |
