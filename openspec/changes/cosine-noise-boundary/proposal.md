## Why

**cosine 作为排序特征的四个前提（四条泄漏判据）已全部通过。**
但它依赖 embedding 的稳定性，而 `AGENTS.md` 登记了"embedding 非确定性"。

**必须先量化：这个非确定性会不会让名次翻转？**

## 实测

### 1. 非确定性只在缓存未命中时出现

| 情形 | 结果 |
|---|---|
| **缓存命中** | `max|diff| = 0.00e+00`，`cos = 1.0000000000` |
| 缓存未命中 | 同文本 `cos = 0.9971`（约 4.36°） |

**`run_retrieval` 走缓存，所以重跑同一份产物是逐位可复现的。**
噪声只在"首次生成缓存"时进入。

### 2. 向量扰动对 `cos(query, candidate)` 的实际影响

用真实数据旋转候选向量 4.36°（等价于缓存未命中的两次调用差异）：

| 量 | 值 |
|---|---|
| 样本数 | 30（10 个 case × 3 条候选） |
| `|Δcos|` 均值 | **0.0019** |
| `|Δcos|` P95 | **0.0051** |
| `|Δcos|` **最大** | **0.0061** |

**按 query-candidate 夹角分桶**（与用户的手推一致：`sin(角度差) × θ`）：

| 夹角 | n | 均值 | 最大 |
|---|---|---|---|
| 40–70° | 26 | 0.0020 | **0.0061** |
| ≥ 70° | 4 | 0.0016 | 0.0021 |

### 3. 关键量：`cosine_gap` = gold − 最强干扰

| subject | 正 gap 最小值 | `gap < 0.006` | `gap < 0.02` | 已排错（负 gap） |
|---|---|---|---|---|
| `sample` | **0.0136**（`ledger-q8`） | **0/10** | 1/10 | **1**（`ledger-q2` −0.0542） |
| `billing` | **0.0447**（`billing-c2`） | **0/12** | 0/12 | **2**（`c3`、`a2`） |

**两个 subject 都没有 case 落在噪声区间内。**

**但有 3 个 case 的 cosine 本身排错了**（负 gap）——那不是噪声问题，是能力问题。

### 4. "池小所以敏感"这个推理不成立

| subject | 池大小 | 正 gap 最小值 | 敏感度 |
|---|---|---|---|
| `billing` | **9**（更小） | **0.0447** | 远大于噪声 |
| `sample` | **12–14**（更大） | **0.0136** | 是噪声的 2.3 倍 |

**决定敏感度的是 tie 的紧密度，不是池大小。**

## 阈值：用 0.01，不是 0.006

**实测噪声最大值是 0.0061**。而用户建议的阈值是 0.006——**判据会卡在自己的边界上**。

| 阈值 | 与噪声最大值的关系 | 判定 |
|---|---|---|
| 0.006 | **小于**噪声最大值 0.0061 | ❌ 边界抖动 |
| **0.01** | **1.6 倍** | ✅ |

## What Changes

**1. 新增 `tests/retrieval/test_cosine_noise_boundary.py`**

| 断言 | 判据 |
|---|---|
| `test_cache_hit_is_bitwise_identical` | 缓存命中 `max|diff| == 0` |
| `test_vector_rotation_delta_bound` | 扰动后 `|Δcos|` 最大值 <= 0.01 |
| `test_threshold_exceeds_measured_noise` | 阈值 0.01 **大于**实测最大噪声 |
| `test_no_case_falls_in_noise_band` | 没有正 gap < 0.01 的 case |
| `test_sensitivity_is_tie_not_pool_size` | billing 池更小但 gap 更大 |
| `test_wrong_cases_are_counted` | 负 gap 的 case 数 == 1/2 |

**2. 报告新增 §6.12.6（噪声边界）**

**3. 记录三个未来字段（不在本变更实施）**

| 字段 | 含义 | 先例 |
|---|---|---|
| `cosine_gap` | gold − 最强干扰 | `tie_at_top1` 是同类概念 |
| `cosine_unstable` | `gap < 0.01` | `tie_resolved_by` |

**4. 记录一条未来验收**

> 稳定 case 的 `SEH@1` 必须等于全部 case 的 `SEH@1`。
> 若不等，说明不稳定 case 影响了结论。

**本变更只做测量与断言，不改产物、不改权重。**

## 验收

| # | 判据 | 可被违反的形式 |
|---|---|---|
| 1 | 缓存命中 `max|diff|` | 必须 == 0 |
| 2 | 噪声最大值 | 必须 <= 0.01 |
| 3 | 阈值 | 必须 > 实测最大噪声 |
| 4 | 噪声带内的 case 数 | 必须 == 0 |
| 5 | 负 gap 的 case 数 | 必须 == 1 / 2 |
| 6 | 报告写"0.01"与"噪声最大值 0.0061" | 缺一必须红 |
