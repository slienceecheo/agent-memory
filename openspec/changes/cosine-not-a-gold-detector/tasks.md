# Tasks

## 0. 为什么要有这个变更

**前三条泄漏判据（均值差 / 唯一最高 / 分布重叠）全部是 `gold vs 干扰项` 的比较。**
而"gold 检测器"的特征恰恰是"gold 与其余差很大"——三条都会通过。

**所以需要一条只看干扰项之间的判据。**

## 1. 检验 A：极差对比（只能提供"可疑"）

- [x] 1.1 实测

  | subject | `gap` | `spread` | 倍数 |
  |---|---|---|---|
  | `sample` | **+0.1453** | **0.0657** | **2.2441×** |
  | `billing` | **+0.0943** | **0.0427** | **4.1118×** |

  **`gap` 是 `spread` 的 2–4 倍**，看起来像"gold 跳出去、干扰项挤在一起"。

- [x] 1.2 **但极差不可靠**
  - 被单个离群值放大
  - "spread 小"不等于"排序无意义"

## 2. 检验 B：秩相关（决定性）

- [x] 2.1 判据

  ```
  q_cos[i] = cosine(query, 干扰项 i)
  g_cos[i] = cosine(gold, 干扰项 i)
  rho = spearman(q_cos, g_cos)
  ```

- [x] 2.2 实测

  | subject | `rho` 均值 | `rho` 中位数 | 正相关 | top-1 一致 | `n_dist` |
  |---|---|---|---|---|---|
  | `sample` | **+0.500** | **+1.000** | **8/10** | **7/10** | **[2, 3]** |
  | `billing` | **+0.500** | **+1.000** | **9/12** | **9/12** | **[2]** |

- [x] 2.3 **结论：未发现 gold 检测器特征**

## 3. 一个我自己修正过的数字

- [x] 3.1 第一版脚本要求 `n_dist >= 3`，`sample` 只有 4 个 case 能进来，
  rho 是 **0.750 / 0.750**

- [x] 3.2 放宽到 `n_dist >= 2` 后，`sample` 变成 **0.500 / 1.000**
  - 原因是 2 个干扰项时 rho 只能取 ±1，其中 2 个 case 是 ±1
  - **加入 2 干扰项的 case 会改变 rho 分布**

- [x] 3.3 报告与常量都已改成 **0.500 / 1.000**
  - 第一次写报告时用了旧值 0.750，被 `test_numbers_match_report` 抓到

## 4. 必须登记的局限

- [x] 4.1 `billing` 每个 case 只有 **2 个干扰项** -> rho 只能取 ±1
- [x] 4.2 `sample` 是**混合的 [2, 3]**——更糟，一半 case 只能取 ±1
- [x] 4.3 所以只能写"未发现"，不能写"证明"

  | 说法 | 强度 | 采用 |
