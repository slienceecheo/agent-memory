## Why

**上一次归档（`lexical-provenance`，第二十次）的核心结论是错的。**

它写的是：

| subject | p | 判定 |
|---|---|---|
| `sample` | **0.0079** | **显著** |
| `billing` | 0.1091 | 不显著 |

并据此得出"结论分裂：`sample` 可解释、`billing` 不可"。

**而那个 p 值是被污染的。**

## 根因：对照组混进了 C 组

```python
b_vals = list(groups["B"].values())
_, p = _perm_test(a_vals, b_vals + list(groups["C"].values()))   # <- C 混进来
```

**同一段代码的注释写的是**：

```python
# A 组与 B 组做检验（C 组与重叠无关，单独报）
```

**注释说 C 组单独报，实现把它混进了对照组。**

## 为什么这会让 p 变小

C 组是"lexical 没召回 gold"的 case，bigram 均值：

| subject | C 组 n | C 组 bigram 均值 |
|---|---|---|
| `sample` | 4 | **0.0000**（全是 implicit，完全无重叠） |
| `billing` | 3 | 0.0104 |

把 4 个 0 混进对照组，对照均值从 0.0400（只有 B）降到 **0.0080**，
于是均值差从 +0.1537 膨胀到 **+0.1857**，p 从 **0.3333 掉到 0.0079**。

## 修正后的三个口径

| 对照 | sample p | billing p |
|---|---|---|
| A vs (B+C)（**上一轮，污染**） | **0.0079 显著** | 0.1091 不显著 |
| A vs B（修正 C 混入） | **0.3333 不显著** | 0.7778 不显著 |
| A1 vs B（再剔除必然命中） | **0.5000 不显著** | **1.0000 不显著** |

**修正后两个 subject 都不显著——"结论分裂"这个发现本身要撤销。**

## 排序空间：比池大小更根本

`lexical` 单路只返回 **1–4 条**，不是整个池（9–14 条）：

| subject | lexical 返回条数 | 空间 = 1 且 top-1 |
|---|---|---|
| `sample` | 1, 2, 0, 0, 2, 2, 0, 1, 1, 1 | **2 条**（q9, q10） |
| `billing` | 4, 2, 2, 4, 1, 2, 2, 1, 0, 2, 1, 1 | **3 条**（a5, a8, c2） |

**空间 = 1 意味着只有 gold 一条进了融合，top-1 必然——那不是排序能力。**

| subject | 报告值 | 剔除必然后 | 随机基线（1/空间） | 随机基线（1/池，错） |
|---|---|---|---|---|
| `sample` | 0.8333 | **0.7500** | **0.6667** | 0.0833 |
| `billing` | 0.8889 | **0.8333** | **0.6111** | 0.1111 |

**所以"lexical 0.83 vs 随机 0.08"这个对比是错的**：正确的随机基线是 0.67 / 0.61，
增益只有 **+0.17 / +0.22**，不是 +0.75。

## 两条"语义命中"的解释也要撤销

| case | 空间 | 我上一轮写的 | 实际 |
|---|---|---|---|
| `billing-c2` | **1** | "语义命中（申报）" | **没得选**，唯一候选 |
| `billing-a3` | 2 | "德国↔欧洲 跨语种" | 共享 bigram 是 **「抬头」**，query 里确有"抬头"二字 |

`a3` 的 query：「德国那边的账怎么开，**抬头**还要写什么？」
`a3` 的 gold：「会议纪要里定的：欧洲客户走欧元发票，**抬头**必须填 VAT 号」

**它是字面命中，不是跨语种语义映射。** `lexical` 是中文 bigram + BM25，
不可能做"德国 = 欧洲"。

## 验收

| # | 判据 | 可被违反的形式 |
|---|---|---|
| 1 | `sample` p | 必须 == 0.3333（不是 < 0.05） |
| 2 | `billing` p | 必须 == 0.7778 |
| 3 | `low_overlap_top1` | 必须 == {a3, c1}（不含 c2） |
| 4 | 报告含"订正"段 | 删掉必须红 |

**验收 1 是本次的核心**：它从"断言方向"改成"断言具体值"。
只断言 `p > 0.05` 时，`p = 0.99` 也会通过——那与 `p = 0.06` 是两件不同的事。
